# Cosmos Stores

This Go module exposes adaptors which map Cosmos SDK Store types to RaccconDB compliant store types.

Currently the DB type from [cosmos-db](https://pkg.go.dev/github.com/cosmos/cosmos-db@v1.1.1) and the KVStore type from [cosmos core](https://pkg.go.dev/cosmossdk.io/core@v1.0.0/store) are supported.
